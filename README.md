# Բլոտ

Բազառ-Բլոտ (4 խաղացող, 2 թիմ) և Բլոտ (2 խաղացող)՝ բրաուզերում։ Կարելի է խաղալ բոտերի դեմ (հեշտ կամ ուժեղ) կամ online՝ ընկերների հետ սենյակով։ Ինտերֆեյսը հայերեն, ռուսերեն և անգլերեն է։

Կանոնները՝ [RULES.md](RULES.md)։

## Գործարկում

Պահանջվում է Node.js 20+։

```bash
npm install
npm run build
npm start          # http://localhost:8787
```

Մշակման ռեժիմ (երկու տերմինալում).

```bash
npm run server     # խաղի սերվեր, պորտ 8787
npm run dev        # կլիենտ, http://localhost:5173
```

Թեստեր.

```bash
npm test
```

## Կառուցվածք

| Թղթապանակ | Ինչ կա |
|---|---|
| `src/engine` | Կանոնների շարժիչ. քարտեր, բազար, ձեռքեր, համադրություններ, հաշվարկ, խաղ |
| `src/bots` | Բոտեր. հեշտ (կանոններով) և ուժեղ (Monte Carlo) |
| `src/ui` | React ինտերֆեյս |
| `src/net` | Online պրոտոկոլ և կլիենտ |
| `server` | WebSocket սերվեր և սենյակներ |
| `test` | Թեստեր |

## Տեղադրում Render-ում

`render.yaml`-ը պատրաստի Blueprint է. Render-ում ընտրեք **New → Blueprint** և այս repository-ն։ Անվճար պլանում սերվերը 15 րոպե անգործությունից հետո «քնում» է, իսկ սենյակները պահվում են հիշողությունում և վերագործարկման ժամանակ կորչում են։
